AutoCare AI — Car Workshop Microservices

A car workshop platform built as Spring Boot microservices. Customers describe a car problem and a Spring AI assistant explains the likely cause and quotes a price, using retrieval-augmented generation (RAG) over the workshop's own guide and live price list, so it doesn't make things up. Customers book and track their car, and mechanics run a job board. A Spring Cloud Gateway handles JWT checks, header-spoofing protection and rate limiting, and every push is tested by GitHub Actions.

Java 21 Spring Boot Spring Cloud Gateway Spring AI PostgreSQL React Docker GitHub Actions
